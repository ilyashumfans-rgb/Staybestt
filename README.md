# StayBest

Hotel booking web application, API, and Expo mobile app.

## Source layout
- artifacts/staybest: web app
- artifacts/api-server: API
- artifacts/staybest-mobile: Expo app
- lib: shared database, API contracts and clients

Use pnpm to install dependencies. Runtime secrets must be configured separately; no credentials are included.

This is a clean public source snapshot. Private workspace history, uploads, screenshots, sample invoices, and the private seed script are intentionally excluded. The scripts seed command is not available in this public snapshot. Store release configuration is not yet complete.
